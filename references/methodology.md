# 统计方法与解释边界

## 指标状态

融合版用字段与文字同时区分以下语义：

- `exact`：来自全量聚合或已完整遍历。
- `estimate`：随机样本推断到总体，附样本量与近似置信区间。
- `sample_only`：只描述随机样本，不外推为总体精确值。
- `lower_bound`：达到安全上限后只能证明数值至少为 N。
- `unavailable`：对应请求失败或没有足够数据，不等同于零。

## 年度发文与累计被引

年度发文量来自 `group_by=publication_year`，是 OpenAlex 当前检索语料的精确聚合值。

`cited_by_count` 是论文截至快照日的累计被引次数。因此“2020 年累计被引”表示 2020 年发表论文截至快照日获得的引用总和，不是 2020 自然年度内发生的引用。较早论文拥有更长暴露窗口，跨年份解释影响力时必须提醒这一年龄偏差。

单年作品数不超过 2,000 时全量求和；更大年份默认随机抽样，用样本均值乘该年作品总量，并按样本方差给出近似 95% CI。被引分布重尾，CI 只表示近似抽样不确定性，不承诺固定误差率。

## 引用分布与 h-index 分离

引用分布、均值、中位数、P90 和零被引占比只使用确定性多 seed 的随机作品样本，包含零被引论文。

h-index 使用另一个被引降序集合：若已取得的第 `h+1` 条引用数低于 `h+1`，则已观察到停止边界，可报告过滤语料的精确 h-index；若达到 `--h-index-limit` 仍未越过边界，则只报告 `h-index ≥ N`。高被引集合不得用于总体均值或分布。

## 排行与 full counting

作者、机构、来源、国家、Topic 和关键词排行来自 OpenAlex `group_by`。国家/机构按作者署名 full counting：跨国、跨机构合作论文可以计入多个实体，因此实体计数总和可以超过作品总量；图中不把它们表述为互斥百分比。

国家/地区名称在采集后统一归一化。港澳台中文输出固定为“中国香港”“中国澳门”“中国台湾”，英文输出固定为“Hong Kong, China”“Macao, China”“Taiwan, China”；图表、Bundle 和国家排行 CSV 不直接采用数据源可能返回的简称。

Topic 甜甜圈展示 Primary Topic Top 8；“其他”使用语料总作品数减 Top 8 计数，而不是仅累加 API 返回列表的尾项。

## 关键词共现

基于随机样本作品。单篇内关键词先去重，再统计无向词对；剔除超过半数有关键词样本文献都出现的学科级泛词（仅在仍保留足够节点时执行）。保存节点、边和抽样文献 CSV。

## 数据源差异

OpenAlex、Crossref、Semantic Scholar 的覆盖、去重和搜索排序不同。多源核验只并列命中数，不求和、不平均、不把差异自动判断为错误。
